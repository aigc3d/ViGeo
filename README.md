# ViGeo Evaluation

Evaluation code for ViGeo and third-party visual geometry baselines.

The repository contains two kinds of entry points:

- `eval.py` evaluates ViGeo.
- `depth_benchmarks/`, `normal_benchmarks/`, `pose_benchmarks/`, and `recon_benchmarks/` evaluate comparison methods.

All scripts should be launched from the repository root. Summary CSV files are written to the repository root.

## Tasks

- Monocular depth estimation
- Video depth estimation
- Point-map estimation
- Surface normal estimation
- Camera pose estimation
- Scene-level 3D reconstruction

## Data Preparation

Put all benchmark data under one root directory, for example `benchmark_datasets/`, or pass another path with `--data-root`.

Download the ViGeo depth, point-map, normal, and Sintel pose benchmark data:

- [bonn.zip](https://virutalbuy-public.oss-cn-hangzhou.aliyuncs.com/share/ViGeo_Benchmark/bonn.zip)
- [hammer.zip](https://virutalbuy-public.oss-cn-hangzhou.aliyuncs.com/share/ViGeo_Benchmark/hammer.zip)
- [kitti.zip](https://virutalbuy-public.oss-cn-hangzhou.aliyuncs.com/share/ViGeo_Benchmark/kitti.zip)
- [nyuv2.zip](https://virutalbuy-public.oss-cn-hangzhou.aliyuncs.com/share/ViGeo_Benchmark/nyuv2.zip)
- [sintel.zip](https://virutalbuy-public.oss-cn-hangzhou.aliyuncs.com/share/ViGeo_Benchmark/sintel.zip)

Prepare 7-Scenes and Neural RGBD for 3D reconstruction:

```bash
python preprocess/prepare_reconstruction_datasets.py --data-root benchmark_datasets --download --extract
```

Expected dataset layout:

```text
benchmark_datasets/
├── sintel/
│   ├── clean/<scene>/*.png
│   ├── depth/<scene>/*.dpt
│   ├── normal/<scene>/*.png
│   └── camdata_left/<scene>/*.cam
├── bonn/
│   └── <scene>/{rgb,depth}/
├── kitti/
│   ├── image/<sequence>/image_02/data/
│   ├── depth/<sequence>/proj_depth/groundtruth/image_02/
│   └── calib/<date>/calib_cam_to_cam.txt
├── nyuv2/test/
│   ├── <id>_img.png
│   └── <id>_normal.png
├── hammer/
│   └── <scene>/{rgb,_gt,normal}/
│       # or <scene>/polarization/{rgb,_gt,normal}/
├── 7scenes/
│   └── <scene>/
│       ├── TestSplit.txt
│       └── seq-<id>/
│           ├── frame-000000.color.png
│           ├── frame-000000.depth.png
│           ├── frame-000000.depth.proj.png
│           └── frame-000000.pose.txt
└── neural_rgbd/
│   └── <scene>/
│       ├── images/img0.png
│       ├── depth/depth0.png
│       └── poses.txt
```

Sintel evaluation uses the `clean` pass. For 7-Scenes, reconstruction evaluation uses the projected `frame-*.depth.proj.png` files generated by the preprocessing script.

## Checkpoints

Put ViGeo weights at `vigeo.pt`, or pass the path with `--checkpoint-path`.

Third-party baseline weights are not included. Download them from the original projects or model hubs according to their licenses. Some baselines load from the default Hugging Face cache.

## ViGeo Evaluation

Run ViGeo evaluation:

```bash
bash scripts/eval_vigeo.sh --data-root benchmark_datasets --checkpoint-path vigeo.pt
```

The ViGeo script writes:

```text
eval_results_vigeo_summary.csv
```

Default ViGeo datasets:

- Depth and point map: Sintel, Bonn, KITTI
- Normal: Sintel, NYUv2, Hammer
- Pose: Sintel
- Reconstruction: 7-Scenes, Neural RGBD

## Baseline Evaluation

Run depth and point-map baselines:

```bash
bash scripts/eval_depth_benchmarks.sh --data-root benchmark_datasets
```

Run normal baselines:

```bash
bash scripts/eval_normal_benchmarks.sh --data-root benchmark_datasets
```

Run a pose baseline:

```bash
bash scripts/eval_pose.sh --model pi3 --data-root benchmark_datasets
```

Run a 3D reconstruction baseline:

```bash
bash scripts/eval_reconstruction.sh --model streamvggt --data-root benchmark_datasets
```

Baseline scripts write:

```text
eval_results_video_depth_summary.csv
eval_results_mono_depth_summary.csv
eval_results_pointmap_summary.csv
eval_results_normal_summary.csv
eval_results_pose_summary.csv
eval_results_reconstruction_summary.csv
```

Supported method names are defined in the corresponding `model_registry.py` files.

## Metrics

- Depth and point map: `absrel`, `d1`
- Surface normal: `mean`, `median`, `a3`
- Camera pose: `ate`, `rpe_trans`, `rpe_rot`
- 3D reconstruction: `acc_mean`, `acc_median`, `comp_mean`, `comp_median`, `nc_mean`, `nc_median`

CSV rows use:

```text
task,dataset,benchmark,<metrics...>
```

Values are written incrementally after each dataset finishes.
